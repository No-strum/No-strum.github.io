# Zhanyuan Tian — Personal Academic Website

A lightweight, responsive static website designed for GitHub Pages.

## Files

- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — navigation + scroll animations
- `assets/Zhanyuan_Tian_CV.pdf` — current site CV download
- `assets/favicon.svg` — favicon
- `assets/Phd.mp4` — PhD whitecap-tracking showcase video (add this file before publishing)

## Preview locally

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

### If your existing site is `no-strum.github.io`

1. Open the repository that publishes `no-strum.github.io`.
2. Back up your current files.
3. Copy the contents of this folder into the repository root.
4. Commit and push to the default branch.
5. In GitHub: **Settings → Pages**.
6. Choose **Deploy from a branch** and select the repository root on your default branch.

## Recommended edits before publishing

1. Replace the Wuhan University email in `index.html` with your current Imperial email.
2. Replace `assets/Zhanyuan_Tian_CV.pdf` whenever you update your academic CV.
3. Add links to Google Scholar, GitHub, LinkedIn, ORCID, and publications when ready.
4. Add a professional portrait or an ocean-research image if you want a more personal visual identity.
5. Once your PhD results are published, add a dedicated Publications section.

## Design intent

The current layout deliberately puts your Imperial PhD research first. Older undergraduate projects are still visible, but they support your present research identity rather than dominating it.
